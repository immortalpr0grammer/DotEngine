# What is this project
This is just some opengl engine thingy i am making.  
Idk if it will get far and for what i will use it.
# Prerequisites for building
- A graphics card or intergrated graphics
- Cmake installed
# How to build this project
Do `cmake -S . -B build` and then `cmake --build build` from the root of the project.  
After that you can rebuild with `cmake --build build` if you made your own changes.
# How to run it
run build/engine in your terminal from the root of the project.
# Keybinds
- Exit: `esc`
- Change between color modes: `enter`
- Move around: `WASD`
- Look around: `mouse`
- Zoom in and out: `scrollwheel`
- Go faster: `shift`
